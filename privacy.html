Privacy Policy

Icarus: Sands of Glory · Icarus dev team · Last updated November 5, 2026

This policy explains what happens to your information when you play Icarus: Sands of Glory (the "game"), including the Android app (package name com.icarus.sandsofglory).

Short version: the game does not collect, store or share any personal information. We have no accounts, no ads, no analytics and no tracking.

Information we collect

None. The game does not ask for your name, email, location, contacts, photos or any other personal information, and it does not create user accounts.

Your saved games

  • Your progress is saved only on your own device, inside the app's private storage. It is never uploaded to us.
  • If you use Save to device or Load file, the game opens Android's file picker. You choose where the backup file goes or which file to load. The game only touches the file you pick.
  • Uninstalling the app deletes the saves stored inside it. Backup files you saved yourself stay where you put them.

Internet use

The game connects to the internet only to:

  • Download game updates from GitHub Pages (github.io), so you get new content without reinstalling the app.
  • Load fonts from Google Fonts.

Like any website, these services receive basic technical information needed to deliver files, such as your IP address and device/browser type. We do not receive or see this information. Their own privacy policies apply: GitHub Privacy Statement and Google Privacy Policy.

Permissions

  • Internet — only for the updates and fonts described above.

The app does not request access to your location, camera, microphone, contacts or files beyond the single file you choose in the file picker.

Advertising and purchases

The game has no ads and no in-app purchases.

Children

The game does not knowingly collect information from anyone, including children under 13, because it does not collect personal information at all.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
